# Personal Expense Tracker

A beginner-friendly HTML, CSS and JavaScript project.

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. Add expenses and try the category filter and delete button.

## Files
- `index.html` – page structure
- `style.css` – styling and responsive layout
- `script.js` – app functionality and LocalStorage

## Features
- Add and delete expenses
- Category selection and filtering
- Total spending and transaction count
- Input validation
- LocalStorage persistence

## Student practice
Try adding a monthly budget, date-based filtering, or a chart of expenses.
